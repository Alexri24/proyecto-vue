# GameStore - Proyecto Vue 3


## Cómo arrancar el proyecto (Docker)
Para levantar el Frontend y el Backend simultáneamente, :
\`\`\`bash
docker-compose build && docker compose up
\`\`\`

La tienda estará disponible en: http://localhost:5173
